# Independent Plan B Implementation Plan

> **For agentic workers:** implement inline, with implementation and validation checkpoints.

**Goal:** Independently implement remote official Claude Code with local execution and files in Remote Dev Kit; borrow no cc-desk-tunnel application/runtime code.

**Architecture:** Keep the native CLI/Harness and account in a separate owned remote container. An rdev-owned local SSH/SFTP executor travels through existing verified SSH using an independently implemented device-stream multiplexer; Unix sockets stay inside the container. Native remote Claude calls this device using ordinary SSH/SFTP, with explicit local-execution context. Native TUI retains conversation, plan, approvals, questions and resume semantics. Optional web access exposes the same terminals through a private tunnel.

**Tech Stack:** Go, existing SSH/SFTP libraries, OpenSSH, Docker, official Claude Code, tmux; optional terminal renderer.

## Global Constraints

- No cc-desk-tunnel application, Electron App, runtime, source patches or protocol dependency.
- Scheme A and native host Claude remain untouched; B credentials/history live in owned data directories.
- Local full-user execution requires explicit enable; no automatic A-to-B fallback.
- No new public ingress, VPN/DNS changes or Docker socket in the container.
- Reset preserves all account, project and conversation data.
- Verify infrastructure without misrepresenting scripted tests as live model acceptance.

Files: `planb_executor.go`, `planb_executor_test.go`, platform process helpers.
