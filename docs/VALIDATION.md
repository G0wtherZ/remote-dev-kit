# Alpha 验证范围

alpha.5 新增的独立 Plan B 验收与平台边界见 [Plan B 验收记录](PLAN_B_VALIDATION.md)。
以下保留默认 A 的历史记录，不把旧实验结果当作 B 的证据。

版本：`0.1.0-alpha.4`。以下是开发验收摘要，不包含个人机器路径、服务器地址、
SSH 主机密钥、设备标识、会话凭据或原始日志。

| 项目 | 验证情况 |
| --- | --- |
| Go 自动化检查 | `go test -race ./...`：含恢复、身份保护、主机密钥和重试边界检查；真实 Chrome 测试默认跳过；`go vet ./...` 通过 |
| 真实 Chrome | 单独启用集成测试，验证导航、截图、点击、输入和查看器认证 |
| 官方 DevTools MCP | 工具发现、页面列表、导航、控制台日志、截图通过；运行环境为本机独立 Chrome |
| macOS ARM64 → Ubuntu x64 | 私网 SSH、FUSE 实时文件读写、含空格和中文路径、共享启停通过 |
| 本机端口授权 | TCP 往返、仅远端回环监听、提前撤销后不可连接通过 |
| 后台服务 | 共享关闭后移除自启动、repair 不擅自重开共享通过 |
| 用户态网络冷启动 | 私有本地 API 可用、未改变系统路由、退出后子进程监听关闭通过 |
| 普通 Linux 用户 | 隔离 Ubuntu 容器内验证创建、密钥登录、参数及工作目录、拒绝 root 启动 Claude |
| 初始安装器 | 隔离 Home 内验证安装、PATH、计划模式与自定义目录；没有连接用户提供的新服务器 |
| 构建 | Darwin、Windows、Linux 的 ARM64/AMD64 六种程序交叉构建完成 |
| 发布包 | 四种本机安装包逐文件 SHA-256 校验；排除私有状态、日志、身份和个人环境标记 |

本次 alpha.2 额外完成：

- VPS 通过临时、限时、需能力凭据的本机接口，触发一块明确授权 USB 存储盘格式化为 exFAT。
- 缺失凭据、指定其他设备、重复格式化请求均被拒绝；测试后接口及转发撤销。
- 真实 USB 盘经 SFTP/SSHFS 实现 4 MiB 上行、8 MiB 下行哈希一致，以及重命名、删除和只读拒绝写入。
- reset 保留模拟 Claude 配置/历史、项目和 USB 文件；损坏助手能够恢复，真实 tmux 持续终端保留。
- 强制终止本工具挂载进程后自动恢复；拔盘、卷 UUID 不匹配时拒绝共享，不创建同名空目录。
- setup 继续设置、修改只读权限，以及共享关闭后 repair 不重开授权均通过。

格式化接口是本次明确授权的实验夹具，未作为通用格式化命令随产品发布。
这验证的是存储文件协作和受限设备操作，**不代表原始 USB/IP、块设备、串口、开发板或调试器透传已验证**。
原始测试记录留在维护者本机，不进入仓库或安装包。

alpha.3 补充：macOS 外接盘路径大小写变体会使用同一卷 UUID 检查，避免小写 `/volumes/`
漏过磁盘绑定。回归测试覆盖正常/大小写路径、错误挂载点和普通目录；已用现有 USB 卷进行
只读实测。该版本未重新格式化磁盘，也没有改变现有 Tailscale、VPN 或系统路由。

alpha.4 补充：

- 本机和助手独立返回 rdev 版本、协议及能力；版本号可以不同，兼容性由协议和当前所需能力判断。
- 31 个顶层 Go 测试通过，另有 2 个子用例通过，1 个真实 Chrome 测试默认跳过；race 与 vet 通过。
- 现有 Mac → Ubuntu VPS 上验证当前助手握手与 doctor、实际 alpha.3 旧助手识别、旧助手更新、助手缺失后恢复。
- 通过真实私网 SSH 注入未来协议与缺失能力的测试元信息，验证操作前拒绝，未创建新共享或端口授权。
- 预检与运行环境读取在隔离 HOME、模拟 Claude 程序及数据下验证：未执行 Claude，模拟配置和项目文件保留。
- 旧助手不会被误报为挂载损坏；授权清理不依赖新协议，错误建议保持当前 state-dir。
- 未改变 Tailscale/SSH 连接方式、主机验证、本机文件边界，未增加本机通用 Shell，也未启用 Plan B。

未来协议/缺失能力使用测试夹具模拟，不代表验证了尚未发布的助手版本。
测试只部署本工具助手到独立临时目录，不更新用户的实际 Claude 程序或账号数据。

未完成的实机验收：Windows、远端 macOS、其他 Linux 发行版、完整重启与休眠恢复。
没有使用真实 Claude 账号调用模型，也没有验证真实 `@` 补全、开发板、烧录、JTAG/SWD 或 Xcode。
浏览器本机集成测试通过不代表 Linux VPS 上的 Chrome 系统依赖已经验收。

复现基础检查：

```sh
go test -race ./...
go vet ./...
python3 scripts/build.py --target darwin-arm64 --target windows-amd64
python3 scripts/test_install.py
```

单独启用 Chrome 集成测试（需要普通用户、本机 Chrome，以及已经构建的本机程序）：

```sh
RDEV_TEST_BINARY="$PWD/dist/assets/rdev/darwin-arm64/rdev" go test -run TestRealBrowserViewer -v
```

将示例二进制路径替换为实际本机平台；不要以 root 执行浏览器测试。
